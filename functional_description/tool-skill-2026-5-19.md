## 🚀 [2026-05-19] 更新日志：构建完备的感知执行层与动态技能系统

本次更新大幅重构并扩展了 `Harness-Lite` 的底层能力，赋予了 Agent 读写项目、受控执行、全网检索以及动态加载业务规范的核心能力，正式确立了从“工具(Tool)”到“技能(Skill)”解耦的现代多智能体架构底座。

### 🧰 一、 核心工具链矩阵 (Toolchain)
新增了 3 大核心维度的物理工具，全面提升单 Agent 的物理操作能力与防幻觉机制：

#### 1. 工作区与文件精细操作层 (Workspace & File IO)
**目标：让 Agent 具备极其安全的“代码审阅与修改”能力。**
* **`list_directory`**: 目录树感知工具，自带深度限制（防止上下文爆炸）并自动过滤无用缓存文件夹。
* **`read_file`**: 文件读取工具，支持按行号范围精准读取，并在输出中附带行号，为后续修改提供基准。
* **`create_file`**: 安全文件创建工具，严格拦截文件覆盖行为。
* **`edit_file`**: **[核心]** 局部代码编辑工具。采用精确字符串匹配（StrReplace）模式，彻底摒弃全量覆写，极大降低代码破坏率。
* **`grep_search`**: 全局检索工具，支持跨文件快速定位函数、变量定义与报错位置。

#### 2. 受控执行与终端沙盒层 (Execution & Sandbox)
**目标：赋予 Agent 运行代码、安装依赖及自我验证的“双手”。**
* **`bash_terminal`**: 受控 Shell 执行器。**内置目录状态机（完美支持 `cd` 切换上下文）**，同时配备防卡死超时机制（Timeout）与输出截断保护。
* **`python_interpreter`**: 独立的 Python 交互式沙盒。允许 Agent 利用临时文件快速运行验证逻辑、清洗数据并安全捕获异常堆栈。

#### 3. 情报检索与网页解析层 (Web & Information)
**目标：打破本地知识库边界，实现动态报错排查与全网搜索。**
* **`intelligence_search`**: 接入针对 LLM 优化的 Tavily 引擎，精准返回清洗后的结构化网页摘要。
* **`web_scraper`**: 网页正文深度提取器。自动过滤广告与 JS 脚本，将目标 URL 转换为干净易读的 Markdown 文本供大模型阅读。

### 🧠 二、 全新动态技能架构 (RAG-Driven Skill System)
**重大架构升级**：彻底将“技能(Skill)”与“工具(Tool)”的底层逻辑解耦，Skill 不再是 Python 代码，而是化身为**即插即用的纯文本上下文外脑**。

* **📄 纯文本驱动 (SOP as Data)**：技能通过 `SKILL.md` 结合头部 YAML 元数据定义。降低编写门槛，开发或业务人员只需编写 Markdown 规范即可赋能 Agent。
* **⚡️ 零配置热加载 (Hot-Swappable)**：框架通过 `skills/__init__.py` 实现自动扫描与挂载。新增或删除技能只需增删文件夹，无需修改引擎代码，启动即生效。
* **📖 动态按需翻阅 (In-Context Retrieval)**：
  * **目录注入**：引擎启动时自动将当前已加载的技能摘要目录注入到系统提示词 (`SYSTEM_PROMPT`) 中。
  * **自主学习 (`read_skill`)**：Agent 在面临专业任务前，通过专属阅读工具主动拉取对应 `SKILL.md` 的详细规范，实现“先学习 SOP，再利用物理工具干活”的**高阶自主推理闭环**。
